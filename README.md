# ☕ Java Playground

### Bringing Java Algorithms to Life

An interactive collection of Java projects that transforms traditional programming concepts into engaging browser-based experiences.

Built with **Java, JavaScript, HTML, CSS, and CheerpJ**, allowing real Java algorithms to run directly in the browser.

**[🚀 Explore Live Demo](https://rnkcd.github.io/Java-Playground/)** | **[💻 GitHub](https://github.com/RNKCD/Java-Playground)**

---

## ✨ Featured Projects

| Project | What It Does |
|---|---|
| 📊 **Sorting Visualizer** | Visualize Bubble, Selection, Insertion, Exchange, Merge, and Quick Sort step by step. |
| 🔍 **Binary Search Challenge** | Explore binary search through interactive challenges. |
| 🧮 **Strassen Matrix Lab** | Experiment with recursive matrix multiplication. |
| 🤖 **Robot Block Simulator** | Simulate robot movements and logical operations. |
| 🎵 **Music Album Explorer** | Explore object-oriented programming with music collections. |
| 📦 **Inventory Manager** | Manage inventory using Java-based application logic. |

## 🛠️ Tech Stack

`Java` · `JavaScript` · `HTML5` · `CSS3` · `CheerpJ` · `GitHub Pages`

## ⚙️ How It Works

```text
User Interaction
       ↓
HTML / CSS / JavaScript
       ↓
CheerpJ Browser Runtime
       ↓
Java Algorithms (.jar)
       ↓
Interactive Results
```

The core algorithms are written in **Java**, while JavaScript handles the interface and visualizations.

## 💻 Run Locally

```bash
git clone https://github.com/RNKCD/Java-Playground.git
cd Java-Playground/docs
python -m http.server 8000
```

Open `http://localhost:8000/` in your browser.
