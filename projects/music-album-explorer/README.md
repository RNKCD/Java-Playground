# Music Album Explorer

A small console-based Java app for browsing a ranked music album CSV dataset.

## Run

From this folder:

```bash
javac Album.java GreatestAlbums.java MusicAlbumExplorer.java
java MusicAlbumExplorer
```

Choose from a numbered menu to display the top albums, search by artist, or filter by decade. Run `java MusicAlbumExplorer albumlist10.csv` for the 10-album sample. The original assignment test is available as `P2Test.java`.
